# 03｜开发循环与任务卡

每完成一张任务卡，必须提交 Git、运行验收、由开发者确认后才开始下一张。不要让 Agent 自动连续完成全部任务。

## 任务 0：工程基线

建立干净 Git 仓库和 `backend/`、`frontend/`。初始化 Maven Spring Boot、Vue 3 + TypeScript + Vite、ESLint、基础 README、Docker Compose（仅 MySQL 开发环境）、Flyway 空迁移、统一错误/响应框架和前端基础布局。

验收：后端 `mvn test`、`mvn package` 通过；前端 `npm run lint`、`npm run build` 通过；前后端各有健康检查/占位页。

## 任务 1：静态页面原型

前端只使用模拟数据，完成首页待回答流、筛选 UI、发帖、详情、一级回复、匿名/公开显示差异、公开主页、我的页面骨架。无真实登录和数据库写入。

验收：匿名无主页入口；公开可进主页；已帮助/已关闭不进默认流；筛选可组合。

## 任务 2：数据库与账号基础

Flyway 建立 users、profiles、字典、帖子、回复、标签、支持、收藏表与索引。实现 Spring Security、密码哈希、开发期注册/登录/退出、JWT 认证过滤器、当前用户上下文、管理员角色基础。编写后端测试。

验收：密码不以明文入库；游客不能访问受保护接口；伪造 userId 无效；Flyway 可从空 MySQL 完整创建库。

## 任务 3：真实核心闭环

实现帖子、回复、支持、收藏、待回答排序、多维内部筛选、公开主页、我的内容、默认身份、楼主标记有帮助和关闭评论。前端改为调用真实 REST API。

验收：两账号测试匿名与公开边界；所有公开响应无 authorId/school/major；B 无法修改 A 内容；匿名内容永远不在公开主页出现。

## 任务 4：删除、通知与隐私体验

实现软删除、浏览历史、通知、用户设置、robots/noindex、隐私页、规则页、加载/空/错误/无权限状态。

验收：删除后的详情、首页与分享链接没有原文；通知和历史仅本人可见；历史可关闭和清空。

## 任务 5：举报、审核、限流与后台

实现举报、拉黑、敏感内容提示、高风险求助提示、服务端限流、审核后台、审计日志、渐进式限制和处理通知。

验收：举报数量不自动处罚；限流和限制状态实际阻止写入；普通用户不可访问后台；风险求助不等于违规。

## 任务 6：内测部署与加固

补齐集成测试、API 文档、Docker 镜像、生产配置、日志脱敏、数据库备份说明。部署前后端和 MySQL，进行 20–50 人受邀内测。

验收：按 `04-开发者配合手册.md` 上线清单逐项通过；至少两账号完整回归匿名、公开、删除、举报、限制、通知。

## 给 Agent 的每轮提示词

```text
完整阅读 docs/v3/00、01、02、03、05 文档，并遵守其中所有规则。
现在只执行任务 N：<名称>。先输出检查与实现计划，再编码；不得提前做后续任务。
完成后运行后端测试/构建与前端 lint/构建，提供可执行验证步骤、需要开发者做的外部操作、学习提示和未完成范围；
并按 00 总指令的"学习整合"要求，写入/更新 learning-notes/任务N-学习笔记.md（含 05 清单逐条解释与代码落点、本模块开发者提问整理），然后停止。
```
