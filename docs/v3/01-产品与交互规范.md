# 01｜产品与交互规范

## 产品定位与首版目标

人生补丁包是面向大学生的公开互助社区。用户可以倾诉、求建议或寻找同路人；其他用户通过公开一级回复提供支持和经验。产品不是心理诊断、治疗或危机干预服务。

首版必须可靠打通：**发布困扰 → 待回答流被看见 → 获得回复 → 楼主标记有帮助或关闭评论**。

首版明确不做：私信、楼中楼、关注/粉丝、排行/勋章、同校圈、学生认证、复杂推荐、内容编辑、AI 心理建议、小程序和 App。

## 身份模式（最高优先级）

帖子与回复均按内容独立选择身份，首次默认匿名。

| 模式 | 对其他用户显示 | 公开主页 |
|---|---|---|
| 匿名 | “匿名”；无昵称、头像、学校、专业、主页、稳定标识 | 不可进入、不可关联 |
| 公开昵称 | 昵称、可选头像 | 可进入公开主页 |

- 公开主页只列出当前仍为公开昵称的帖子和回复。
- 匿名内容、收藏、浏览历史、举报、账号资料、邮箱、限制状态均不公开。
- 公开内容可被作者改成匿名，并立即从主页移除；匿名内容不能再变公开，防止匿名承诺被事后改变。
- 学校、专业方向只用作内部筛选条件；无论匿名还是公开身份，帖子卡片、详情、主页和 API 均不得返回这些字段。

## 页面与访问权限

| 页面/功能 | 游客 | 登录用户 |
|---|---|---|
| 首页、筛选、帖子详情、公开主页 | 浏览 | 浏览 |
| 注册、登录 | 可用 | 可退出 |
| 发帖、回复、支持、收藏、举报、拉黑、我的、通知 | 跳转登录 | 可用 |
| 管理后台 | 不可用 | 仅管理员 |

主导航：首页、发帖、我的；帖子详情、公开主页、通知、登录是二级页面。用户端先保证清晰手机响应式，再完善手账视觉。

## 首页、排序与筛选

默认展示全站待回答内容，不按热度或支持数排序：

1. **待回答**：无可见回复，优先显示。
2. **待帮助**：有回复、未标记有帮助、评论未关闭，随后显示。
3. **已获得帮助**：至少一条有帮助回复，或评论关闭，不在默认流显示。

同状态按发布时间早者优先；筛选后在结果集内维持该排序。

筛选为多维交集：学校、专业方向、帖子意图、话题标签；标签多选使用任一匹配。学校来自预置可搜索列表，专业方向是固定大类，标签来自固定库且每帖 1–3 个，均不允许用户自由创建。

## 帖子、回复与互动

- 发帖必填：帖子意图（倾诉/求建议/找同路人）和正文。可选：标题、学校、专业方向、标签。
- 一级回复，不做回复的回复。
- 楼主可标记/取消标记“有帮助”，关闭/重新开放评论。
- 作者可删除自己的帖子和回复；删除后立刻不再公开显示。
- 同一用户每帖最多支持一次，可取消；仅显示总数，不显示支持者，不参与首页主要排序。
- 收藏只给本人查看。

## 我的、通知、治理

- “我的”：我的帖子、我的回复、收藏、浏览历史、账号设置、拉黑、举报记录；全部仅本人可见。
- 通知：新回复、内容处理、举报处理、账号安全；仅新回复可关闭。
- 浏览历史默认保存 30 天，可关闭、可清空。
- 举报原因：骚扰辱骂、广告诈骗、泄露隐私、危险内容、其他。
- 自伤、自杀、伤害他人等疑似即时风险内容显示明确求助提示并进入优先审核；普通情绪崩溃不是违规。
